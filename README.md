# Hatpicker 2

A small static web app: three faces stand still in a row, a top hat
swings back and forth above them, and on click the hat slows down over
the random winner and drops onto their head.

## Run locally

```bash
python3 -m http.server 8766
# then open http://localhost:8766/
```
